# 巡防百科首页与法律法规库改版设计

## 背景与目标

本次改版服务街面警力快速进入重点学习内容，并降低法律法规全文页面的检索负担。改动限定为四项：顶部导航增加首页入口、首页每月一学区域展示往期、法律法规库按章节收敛并标注街面常用条文、首页突出人民警察内务规范与体能考核要求。

完成后的用户应当能够：

- 从任意页面通过顶部导航直接返回首页。
- 在首页同一区域查看本月主题和近期往期主题。
- 先浏览法律章节，再按需展开章节查看法条。
- 通过“街面常用”标识和四至六字核心短语快速定位重点法条。
- 从首页左右重点入口直达人民警察内务规范和体能考核要求。

## 方案选择

法律法规库采用数据驱动生成方案。法条原文、章节结构和街面常用短语统一维护在 `data/legal-documents.json`，由 `tools/build_legal_pages.py` 生成法律页面。页面不通过运行时脚本拼接第二份法条清单，也不手工修改生成结果中的结构。

这一方案保证法规内容更新后，章节目录、正文折叠、快捷入口和街面常用标注能够随页面重新生成，不会互相偏离。

## 顶部导航

`js/nav.js` 的导航配置在首位增加“首页”，目标为站点根目录的 `index.html`。首页路径下该栏目显示活动状态；模块页、文章页、每月一学和更新记录页均可通过该入口返回首页。

首页入口作为普通导航项，不使用“更新记录”和“本月精选”的徽章样式。移动端仍由现有汉堡菜单承载，不增加新的导航层级。

## 首页每月一学与往期回顾

首页原有每月一学横幅改为同一容器内的左右组合：

- 左侧展示当前月份、主题、摘要和“查看全文”入口。
- 右侧展示“往期回顾”、最近的往期主题和“查看全部往期”入口。
- 左右两侧共用警蓝渐变背景、白色正文和琥珀金强调色，通过低对比度竖向分隔线区分，不使用独立白色卡片。
- 往期条目继续从 `meiyueyixue/data.js` 读取，排除当前期并按月份倒序排列；首页显示最近三期，完整往期仍可在每月一学页面查看。
- 没有往期时显示简短空状态，不渲染失效链接。

常规桌面使用左右两栏；窄屏改为上下排列，但保持同一背景和视觉连续性。

## 首页重点飘窗

首页增加两个同结构的重点学习入口：

- 左侧“人民警察内务规范”，链接 `zoufang/neiwu-tiaoling.html`。
- 右侧“体能考核要求”，链接 `zoufang/tineng-kaohe.html`。

飘窗采用“重点学习提示牌”形式：警蓝或勤务青标题区、暖白内容区、琥珀金小标签和现有圆角阴影。两个入口结构一致，仅通过标题区色调和文字区分。所有颜色来自现有 CSS 主题变量，必须兼容暖警蓝、经典暖棕、日间浅色和夜间深色。

响应式行为：

- 宽屏且两侧空间充足时，入口固定在首页主体内容区左右，不遮挡搜索框、每月一学或模块卡片。
- 宽度不足以容纳两侧入口时，入口移入首页正文，在每月一学区域下方并排展示。
- 手机端上下排列，保持完整点击区域和清晰文字。
- 飘窗只出现在首页，不注入模块页或文章页。

## 法律目录与正文章节折叠

有完整章节数据的法律页面使用原生 `details` 和 `summary`：

- 法律目录初始只列章节名称。
- 点击某一目录章节后，才显示该章法条链接。
- 法规正文也按章折叠，章节标题作为展开控件，法条原文位于对应章节内。
- 键盘可聚焦并展开章节，展开状态由浏览器原生语义表达。
- 访问 `#article-N` 深链接时，页面脚本找到目标法条所属章节，先展开该章节，再滚动定位目标。
- 无 JavaScript 时仍能手动展开章节阅读完整法条。
- 没有章节数据的法规占位页维持现有提示，不生成空折叠控件。

目录不再初始平铺全部法条，从而降低长法规页面的首屏高度和视觉密度。

## 街面常用法条数据与展示

在相关法条对象上新增可选字段：

```json
{
  "number": 9,
  "label": "第九条",
  "street_note": "盘问检查条件",
  "paragraphs": ["……"]
}
```

`street_note` 的约束为：

- 只使用四至六个汉字。
- 每条法条最多一个短语。
- 短语直接概括该条核心规定，不写完整解释句。
- 短语从街面盘查、现场处置、治安管理、强制措施、警械武器、执法程序、群众权益等场景中选择最贴切的核心概念，例如“盘问检查条件”。
- 不添加统一免责声明或“初稿供学习定位”等附加文字。

正文标题的展示顺序为“法条条号—街面常用标识—核心短语”。只有存在 `street_note` 的法条才显示标识和短语。页面顶部“巡防常用条款”快捷入口由这些字段自动生成，不再单独维护 `xunfang_articles` 数组。

重点法条筛选覆盖与街面工作直接相关的盘查查验、现场制止、治安处置、强制措施、警械武器、执法程序和群众权益保护。筛选和短语初稿以项目现有法规原文及其官方来源为基准逐条核对，不改写法条原文。

## 文件边界

预计修改：

- `js/nav.js`：首页栏目及活动状态。
- `index.html`：重点入口挂载位置。
- `js/monthly-hero.js`：当前期和往期组合渲染。
- `meiyueyixue/data.js`：继续作为月学唯一数据源，不复制数据。
- `css/style.css`：月学组合区、重点飘窗、章节折叠和重点法条标识样式。
- `data/legal-documents.json`：重点法条的 `street_note` 初稿。
- `tools/build_legal_pages.py`：章节目录、正文折叠、快捷入口和标识生成。
- 必要的轻量页面脚本：处理法条深链接自动展开；优先合入现有 `js/main.js`，不新建单用途脚本，除非现有职责边界不适合。
- 由生成器更新的法律法规库 HTML 页面。
- 对应测试文件。

不调整六大模块的名称、顺序、文章内容和现有认证流程，不重构无关页面。

## 可访问性与主题

- 原生折叠控件保留明确的可见焦点和展开状态。
- “街面常用”不能只依靠颜色表达，必须有文字标识。
- 首页重点入口使用真实链接，整个卡片可点击并保留键盘焦点。
- 移动端不得出现横向溢出或飘窗遮挡。
- 新增样式使用现有主题变量，并在四种主题下检查文字对比度和边框可见性。
- 尊重现有减少动画设置；本次不增加持续漂移动画。

## 测试与验收

自动化测试覆盖：

- 首页为顶部导航首个栏目，根路径活动状态正确，内页链接前缀正确。
- 首页重点入口分别指向两篇教育学习文章。
- 每月一学首页组件包含当前期和倒序往期，且不会把当前期列入往期。
- 法律目录只在章节展开后显示法条链接，正文按章节生成折叠结构。
- 所有 `street_note` 均为四至六个汉字，且对应真实法条。
- “巡防常用条款”快捷入口与 `street_note` 自动保持一致。
- 法条深链接能够展开所属章节并定位。
- 生成后的法规页仍包含全部法条原文和稳定的 `article-N` 锚点。
- 全站链接、站点结构、主题样式和现有测试全部通过。

视觉验收覆盖首页宽屏、普通笔记本、手机布局，以及暖警蓝、经典暖棕、日间浅色和夜间深色四种主题。重点检查往期区域色调统一、飘窗不遮挡、目录密度下降和重点短语可快速扫读。
