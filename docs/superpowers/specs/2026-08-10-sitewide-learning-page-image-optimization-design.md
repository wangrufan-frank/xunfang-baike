# 全站学习页面配图优化设计

日期：2026-08-10

## 1. 背景

巡防百科当前共有 93 个学习页面。现有配图主要集中在装备操作和实战训练模块，其他模块存在较大配图缺口；部分已有图片只能帮助识别实物，尚不能充分解释正文中的结构、步骤、对比、场景关系或检查要点。

本轮优化覆盖全部 93 个学习页面。是否已有图片不再作为排除条件：已有图片充分的页面保持现状；图片不足的页面追加；质量、相关性或可追溯性不合格的图片替换；图片不能提升理解效率的页面允许保持少图或无图，但必须记录明确的评估结论。

## 2. 目标与非目标

### 2.1 目标

- 对全部 93 个学习页面完成配图评估。
- 让每张新增或保留的图片服务于一个明确的正文知识点。
- 建立统一、美观、具体且适合移动端阅读的教材信息图视觉体系。
- 使用公开实物图帮助读者识别对象，使用原创 SVG 帮助读者理解结构和流程。
- 保证新增内容、图片来源和版权状态可追溯。
- 建立可复用的配图评估台账和自动化约束。

### 2.2 非目标

- 不为满足固定数量而添加纯装饰图片。
- 不对所有页面强制采用相同版式或相同图片数量。
- 不重命名或迁移现有合格图片。
- 不借配图优化扩写与当前页面主题无关的业务内容。
- 不把前端配图作为内部资料或敏感信息的发布渠道。

## 3. 范围

本轮覆盖六个模块的全部学习页面：

- 装备操作：28 页
- 勤务工作：13 页
- 实战训练：15 页
- 警情处置：6 页
- 法规制度：17 页
- 走访教育：14 页

合计 93 页。

每个页面必须产生以下四类决策之一：

1. **保留**：现有图片清晰、相关、可追溯，且已充分支撑正文学习。
2. **追加**：现有图片合格，但缺少必要的结构、步骤、对比或场景解释。
3. **替换**：现有图片模糊、失真、过度抽象、相关性弱或来源状态不合格。
4. **无需配图**：图片不能显著提高该页理解效率，并在评估台账中说明理由。

## 4. 内容边界

信息图以当前页面正文为主要内容来源，可以适当补充帮助读图的短标签、顺序词、风险提示或部件名称。

涉及以下内容时，不得仅凭绘图需要自行推断：

- 操作要求
- 法律结论
- 处置标准
- 禁止性或强制性要求
- 具体风险边界

此类新增内容必须具有权威公开依据，并同步更新页面引用和公开来源台账。不能确认准确性的内容不进入图片。

## 5. 视觉方向

新增 SVG 采用统一的“现代警务教材信息图”视觉体系。

### 5.1 基础视觉规则

- 主色延续网站暖警蓝。
- 使用低饱和绿色、橙色和红色分别表达正常、提醒和风险。
- 以白色或浅灰蓝为主要背景，避免大面积深色和装饰性渐变。
- 标题、编号、标签形成明确的三级信息层级。
- 图片内只保留理解图形所需的短文本，不复制大段正文。
- 中文在手机端保持清晰可读。
- 流程连线必须表示真实顺序、条件或对应关系，不能仅作装饰。
- 每张 SVG 使用响应式 `viewBox`，在桌面和窄屏下均不得裁切或横向溢出。

### 5.2 形象化要求

- 人物使用具有明确姿态、朝向、手部位置和相互关系的扁平插画，不使用火柴人。
- 器材使用能够被直接辨认的简化外形，必要时用引线标注部件。
- 场景图必须表达人员、物体、区域与风险源的空间关系。
- 禁止只使用通用图标、彩色方框和空泛箭头构成整张图。

### 5.3 六类信息图

1. **结构标注图**：装备组成、部件名称、检查位置和佩戴关系。
2. **分步流程图**：操作顺序、警情处置、工作流程和训练步骤。
3. **场景分区图**：站位、人员分工、现场区域、沟通对象和风险源关系。
4. **对比辨析图**：正确与错误、适用与不适用、不同情形和法律边界。
5. **教材清单图**：检查事项、准备要点、记录要求和复盘框架。
6. **法规关系图**：法律层级、权利义务、程序节点和适用关系。

同一页面最多采用两种主要图型。公开实物图负责“认识对象”，SVG 负责“理解结构或流程”，两者不得重复表达同一信息。

## 6. 单页配图原则

- 普通知识页通常配置 1 张核心学习图。
- 页面包含多个相互独立的知识结构时，可以配置 2 至 3 张。
- 已有图片充分的页面可以不新增图片。
- 图片应插入最相关的正文段落附近，不统一堆放在页首。
- 每张图片必须具有准确的 `alt`、图注、来源和用途说明。
- 每张新增图片必须能够回答“它帮助读者理解正文中的什么”。

## 7. 素材与版权规则

- 优先使用用户自有、明确允许复用或具有清晰开放许可的实物图片。
- 政府或权威网站可以作为事实和内容依据，但公开可见不等于图片可以自由转载。
- 权属不明确的实物图不复制到站内，改为依据可核验事实自行绘制原创 SVG。
- 不在 SVG 中临摹具有明显版权特征的摄影构图、插画或商业产品宣传图。
- 外部素材必须记录原始页面、发布主体、获取日期和许可说明。

## 8. 数据与文件组织

### 8.1 配图评估台账

新增 `data/image-optimization-plan.json`，覆盖全部 93 页。每条记录至少包含：

- 页面路径和所属模块
- 当前图片数量和类型
- 当前图片的清晰度、相关性和可追溯性结论
- 正文中适合图解的知识点
- 配图决策：保留、追加、替换或无需配图
- 计划图型
- 计划插入位置
- 预期学习作用
- 素材来源状态
- 实施状态
- 验收状态
- 无需配图或暂缓处理的具体理由

### 8.2 新增图片目录

新增图片按模块存放：

```text
img/learning/
  zhuangbei/
  qinwu/
  xunlian/
  jingqing/
  fagui/
  zoufang/
```

新文件使用页面 slug 和图形用途命名，例如：

```text
img/learning/jingqing/zuijiu-lei-chuzhi-flow.svg
img/learning/zhuangbei/fangci-fu-structure.svg
```

现有合格图片不迁移、不改名。

### 8.3 既有台账

- 新增或替换图片时，更新 `data/content-inventory.json` 中对应页面的图片信息。
- 图片引入新增知识结论时，更新 `data/public-sources.json` 和页面引用。
- 页面改动完成后重建 `search-index.json`。

## 9. 实施流程

每个页面按以下流程处理：

1. 读取正文和现有图片。
2. 在配图评估台账中记录当前状态和处理决策。
3. 识别最适合图解的具体知识点。
4. 必要时查找权威公开依据或许可明确的素材。
5. 制作实物图或定制 SVG。
6. 将图片插入最相关的正文段落附近。
7. 更新内容清单、图片来源和公开来源台账。
8. 运行页面级结构检查和视觉检查。
9. 完成模块批次后运行全站验证。

如果素材权属、正文准确性或图示含义不能确认，该页面不得强行发布图片。台账将其标记为待确认，并继续处理其他页面。

## 10. 实施批次

### 批次一：全站评估

完成 93 页的配图评估台账，不在评估完成前批量插图。

### 批次二：装备操作与实战训练

优先建立结构标注、动作步骤、检查清单和训练复盘的成熟样式。

### 批次三：警情处置与勤务工作

重点制作场景分区、处置流程、沟通要点和协同关系图。

### 批次四：法规制度与走访教育

重点制作程序关系、权利义务、对比辨析、学习检查和复盘图。

### 批次五：全站统一验收

统一检查图片质量、来源状态、移动端显示、跨页面一致性和更新记录。

每个内容批次先交付少量代表页供用户检查。视觉方向经确认后，再完成该批次剩余页面，避免同类问题扩散到全站。

## 11. 自动化与测试

在现有测试基础上增加配图相关约束：

- 评估台账必须覆盖 `data/content-inventory.json` 中全部 93 个页面。
- 每个页面必须具有唯一且有效的配图决策。
- 新增图片路径必须存在。
- 新增 `<img>` 必须具有非空 `alt`。
- 新增 `<figure>` 必须具有对应图注。
- 新增 SVG 必须具有有效 `viewBox`，不得引用远程图片资源。
- 外部图片必须具有来源和许可记录。
- 被替换图片不得继续被运行页面引用。
- 新增知识结论必须具有有效来源引用。

继续运行仓库现有完整验证：

```powershell
python -m unittest discover -s tests -p "test_*.py" -v
node --test tests/auth_core.test.js
python tools/build_search_index.py --check
python tools/check_site_links.py
python tools/public_source_index.py check
```

视觉验收至少覆盖代表性桌面宽度和手机宽度，检查：

- 裁切和横向溢出
- 图片内文字重叠和最小可读字号
- 图注换行
- 深色主题和非默认主题下的容器显示
- 人物、器材、顺序和空间关系的直接可辨认性

## 12. 完成标准

- 93 页全部具有明确、可审计的配图评估结论。
- 所有计划新增或替换的图片均已完成，或因明确阻碍记录为待确认。
- 每张新增图片对应具体正文知识点，不存在纯装饰或重复图片。
- SVG 在桌面和窄屏下无裁切、溢出、文字重叠或不可读文字。
- 所有新增图片路径、替代文本、图注、来源和许可信息完整。
- 搜索索引、站内链接、来源台账及完整自动化测试全部通过。
- 代表页面完成桌面端和手机端视觉验收。
- `data/updates.json` 记录本轮全站图文学习优化。
